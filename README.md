# 🚀 Production-Ready RAG AI Agent

Bu loyiha haqiqiy "production" darajasidagi Retrieval-Augmented Generation (RAG) agentini yaratishga qaratilgan. Dastur quruq API chaqiruvlaridan qochib, xatoliklarni qayta ishlash (retries), navbatga qo'yish va barqaror AI tizimini qurishni ta'minlaydi.

## 🌟 Asosiy Imkoniyatlar (Features)
* **Web Scraping:** BrightData orqali kerakli ma'lumotlarni ishonchli tarzda yig'ish.
* **Workflow Orchestration:** Inngest yordamida uzluksiz jarayonlarni boshqarish va xatoliklarni oldini olish.
* **Vector Database:** Qdrant orqali hujjatlarni vektor shaklida saqlash va aqlli semantik qidiruvni amalga oshirish.
* **AI & LLM:** LlamaIndex yordamida hujjatlarni qismlarga ajratish (chunking) va to'g'ri kontekstni modelga uzatish.

## 🛠 Texnologiyalar (Tech Stack)
* **Dasturlash tili:** Python
* **AI Framework:** LlamaIndex
* **Ma'lumotlar bazasi:** Qdrant (Vector DB)
* **Infratuzilma va Ops:** Inngest, BrightData
